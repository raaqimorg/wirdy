# Wirdy docs

The index of the docs: one line each, with what it holds and when to read it. Add a new doc here in the same commit.

## Content

- [Content](content.md): what goes in and stays out, the occasions, the file, the text, how to check a dhikr, and the proof. Read it before you add or change a dhikr.

## Branding

- [Branding](branding/README.md): the name, the words, the mark, the colors, the type, the emblems and cards, and each page's metadata. Read it before you change anything a reader or a link preview sees. It is the source of truth for the visuals, and `src/lib/branding.test.ts` keeps it equal to the code.

## Code

- [Code conventions](code-conventions.md): the rules no tool checks, TypeScript, motion, and comments. Read it before you write code.
- [Naming](naming.md): folders, files, functions, types, constants, tests, and scripts. Read it before you name or place anything.
- [Testing](testing.md): the three suites, what to test, and where. Read it before you write a test.
- [Design system](design-system.md): the tokens, an occasion's color, the CSS names, and the components. Read it before you change a style or a component.
- [Exceptions](exceptions.md): the unusual choices, and why each stays. Read it before you build anything unusual.
- [Emblem ideas](emblem-ideas.md): the emblems drawn and not chosen, for a new occasion.

## Working here

- [Development](development.md): the setup, the commands, the git hooks, and the generated files.
- [Writing](writing.md): the rules for docs, commits, and pull requests.
