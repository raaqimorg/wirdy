# Wirdy docs

This is the index of everything the repo knows. Each doc has one line that says what it holds and when to read it. Add a new doc here in the same commit.

## Content

- [Content](content.md): what goes in, what stays out, the occasions, the file, the text, how to check a dhikr, and the proof. Read it before you add or change a dhikr.

## Code

- [Code conventions](code-conventions.md): the code rules no tool checks, TypeScript, motion, and comments. Read it before you write code.
- [Naming](naming.md): the names of folders, files, functions, types, constants, tests, and scripts. Read it before you name or place anything.
- [Testing](testing.md): the three suites, what to test, and where a test goes. Read it before you write a test.
- [Design system](design-system.md): the tokens, the color of an occasion, the CSS names, and the components. Read it before you change a style or a component.
- [Exceptions](exceptions.md): the unusual choices, and why each one stays. Read it before you build anything unusual.
- [Emblem ideas](emblem-ideas.md): the emblems drawn and not chosen, for a new occasion to take.

## Working here

- [Development](development.md): the setup, the commands, the git hooks, and the generated files.
- [Writing](writing.md): the rules for docs, commits, and pull requests.
